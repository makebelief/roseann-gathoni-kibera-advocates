## Preview
Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000. For links and API support use Vercel.

## Contact form setup (Vercel)
The `/api/contact.js` endpoint sends email using Resend. Configure `RESEND_API_KEY` and a verified `CONTACT_FROM_EMAIL` in the Vercel project settings. Until configured, the form shows a clear failure message and provides the direct email address.

## Publishing checklist
